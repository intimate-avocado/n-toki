# VALUES

N-Toki is a solar timekeeper. These are the commitments that make it what it is. They are not marketing. They are constraints. If a future version breaks one of them, it is no longer N-Toki.

## No accounts required

The core app works identically with zero accounts, zero sign-in, and zero identity. Any future social feature is optional forever. A user who never enables it makes zero network requests.

## No tracking

No analytics. No telemetry. No third-party scripts. No CDN fonts: every font ships with the app. Location is used on the device to calculate sunrise and sunset and is never transmitted. Deleting the app deletes everything.

## No ads. Ever.

Attention is not a resource this project monetizes. A timekeeper that steals your attention to sell it back would be the exact thing this app exists to critique.

## No gatekeeping

The free version is complete, not crippled. There is no premium tier that unlocks features, "better hours," or more time. If a paid tier ever exists, it pays for *hosting*, never for access to the thing itself.

## Labor is paid. Users are not sold.

This project may earn money. That is not a contradiction — it is the difference between two things:

- **Selling your labor** to an institution that wants to use the software, or to deploy and support it, is fine.
- **Selling the user** — their attention, their data, their access — is not.

Workplace and institutional adoption is welcome. If an employer uses N-Toki to give people humane rhythms instead of clock discipline, that is a win. If it is used as a punch clock, that is a failure of the deployment, not a license to monetize it differently.

## Time doesn't run out. It flows through us.

The product, the copy, and the interface must all agree with this sentence. Any element that expresses time as a budget being spent — a percentage, a countdown, a streak, a "you're late" — is a bug.
